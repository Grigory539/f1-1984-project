*** Анализ сезона Формулы-1 1984 года ***
Ники Лауда выиграл чемпионат с минимальным преимуществом над Аланом Простом в 0,5 очка, а Макларен доминировал, выиграв 12 из 16 гонок.


# ELT проект с автоматизацией через Airflow и визуализацией в Power BI
Проект включает полный ELT процесс: от сбора данных с сайта statsf1.com до создания интерактивных дашбордов. 
Данные автоматизированно загружаются через Airflow, трансформируются SQL-скриптами и визуализируются в Power BI.

# ELT Процесс

**Extract (Извлечение)**
    Парсинг данных с statsf1.com (Python + requests + pandas)
    Сохранение в CSV файлы
    Обработка HTML таблиц

**Load (Загрузка)**
    Чтение CSV файлов через pandas
    Переименование колонок (английские → русские)
    Замена "-" на NULL
    Загрузка в PostgreSQL через to_sql()
    Добавление pilot_id (SERIAL PRIMARY KEY)

**Transform (Трансформация)**
    SQL скрипт transform.sql (~500 строк)
    DROP старых таблиц → CREATE новых → INSERT данных
    Очистка данных (WHERE ... != 'NaN', != '', IS NOT NULL)
    CAST типов данных (VARCHAR → SMALLINT, DECIMAL)
    JOIN таблиц для аналитики
    CASE для расчёта очков (9-6-4-3-2-1)
    UPDATE для half_points (Монако — дождь)
    

# Оркестрация
Airflow DAG с 3 задачами:
    load_csv_files — загрузка CSV в staging
    sql_transform — выполнение SQL скрипта
    check_result — проверка результата (COUNT)
Автоматический retry при ошибках (1 попытка)
Логирование всех шагов
